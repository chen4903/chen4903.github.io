## 系统性地
做一件事情，需要系统性地去解决，thinking > doing，先要思考好之后，再下手去做。如果事情太大，要学会simplify。我总是很容易把问题复杂化，并且想着一次性把事情完成。而一种好的解决方式是resolve the problem step by step。把大问题分解成一个一个小问题，一个一个去解决，如果分解之后还是觉得难、大、多，则继续拆解，直到自己能够去理解、去完成。

## 如何去交流
这里特指的是书面/文字上的交流，当然口头交流也可以作为借鉴。下面的交流方式使我们高效：
- Clear
- Simple: less word, more information
- 换位思考
- Tips for writers

  - Use less than 30 words per sentence

    ```
    Due to the fact that => because
    Totally lacked the ability => could not
    ```

  - Replace adjective with data

    ```
    We made the performance much faster =>
    We reduced server side tp90 latency from 10ms to 1 ms
    ```

  - Eliminate weasel words

    ```
    nearly all customers => 87% of Prime members
    significantly better => +25% basic points
    ```

  - If you get a question, reply with one of the for answers

    - yes
    - no
    - A number
    - I don't know(and I will follow up when I do)

  - Avoid jargon and acronyms as they exclede non-experts and newcomers

  - Always explain technical terms, acronyms, and abbreviations the first time they appear

    ```
    Example: "After we sign the Non-Disclosure Agreement(NDA)"
    ```

  - Weasel words are vague and create the impression of meaning. Don't use them.

    ```
    1. Would help the solution
    2. Might bring clarity
    3. should result in benefits
    4. significantly
    5. arguably the best
    ```
